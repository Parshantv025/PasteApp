# 📋 PasteApp

**PasteApp** is a modern, web-based clipboard and note-taking application designed to help users quickly store, organize, and manage text snippets, code blocks, and links in one place.

---

## ✨ Features

- ⚡ **Fast & Responsive:** Built with React and Vite for near-instant load times and clean UI interactions.
- 📝 **Create & Edit Snippets:** Quickly create, view, and organize your text or code snippets.
- 📋 **One-Click Copy:** Easily copy any saved content directly back to your clipboard.
- 🔍 **Search & Filter:** Find stored items instantly using keywords.
- 🎨 **Clean Modern UI:** Styled using Tailwind CSS for an intuitive visual experience.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** Tailwind CSS
- **Icons & UI Utilities:** Lucide React / React Icons
- **State Management:** React Redux / Context API
